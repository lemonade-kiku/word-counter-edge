# 选中字数统计（Edge 浏览器插件）

> GitHub 仓库：https://github.com/lemonade-kiku/word-counter-edge

按住 **Shift + 鼠标左键** 选中网页上的文字（普通拖选不触发），会自动弹出一个悬浮小窗，显示选中内容的：

- **字数**（不含空格，汉字按字计）
- **词数**（汉字 + 英文单词）
- 汉字数、英文单词数

选中的文本发生变化（比如又 Shift 拖选了另一段文字），悬浮窗内容会实时更新为新文本的统计。

## 安装方法

1. 打开 Edge 浏览器，地址栏输入 `edge://extensions/` 并回车
2. 打开左下角「开发人员模式」开关
3. 点击「加载解压缩的扩展」
4. 选择本文件夹（`word-counter-edge`）
5. 完成！随便打开一个网页，按住 **Shift + 鼠标左键** 选中一段文字试试

## 使用说明

- **Shift + 鼠标左键拖选**文本 → 悬浮窗出现在选区上方（普通拖选不弹窗）
- 键盘选择同样支持：`Shift + 方向键`、`Ctrl + A` 全选
- 输入框 / 搜索框 / 评论框里的选中文本同样支持
- 悬浮窗**只有点击右上角 ✕ 才会关闭**；点击页面、滚动页面均不会收起，选中新文本时自动更新内容；**审查进行中点击 ✕ 会中止本次审查并收起**

## 常见问题

- **修改了代码不生效？** 回到 `edge://extensions/`，点插件卡片上的「重新加载」按钮
- **PDF 页面不显示？** Edge 自带的 PDF 阅读器不支持浏览器插件，属正常现象
- **不想要了？** 在 `edge://extensions/` 里直接关闭或删除该插件即可

## 📝 论文审查功能（v1.1.0 新增）

选中文本后，悬浮窗上多了一个 **「📝 论文审查」** 按钮。点击后，插件会把选中文本发送给**本地运行的 Claude Code**，按论文写作规范审查三方面：

1. **内容正确性**：语法、拼写、逻辑、事实表述
2. **表达地道性**：是否符合学术语体，有无口语化 / 中式英语
3. **写作规范**：句式结构、时态语态、标点、术语一致性、段内衔接
4. **文献核对**：如果选中文本引用了具体论文，会先在本机 `Documents\scientific_research`（重点 `paper_reading\`）里查找原文 PDF 并阅读核对，逐项检查你的表述与原文有无出入（数值、结论、方法、观点归属等）；找不到原文会明确说明"无法核对"

审查结果（总体评价 + 问题清单 + 修改建议 + 润色后版本）会直接显示在悬浮窗里，可一键复制。

### 使用前提（一次性准备）

1. 电脑上装有 **Node.js**（`node -v` 可验证）和 **Claude Code CLI**（`claude --version` 可验证）
2. **双击运行** `bridge\start-bridge.bat`，保持黑色窗口开启（服务地址 `http://127.0.0.1:8899`）
3. 回到 `edge://extensions/` 点「重新加载」，然后重新加载测试网页

之后每次使用：先双击 `start-bridge.bat`，再在网页里选中文字点「论文审查」即可。审查结果**流式回显**——Claude 的正文按输出块逐段显示；文献核对阶段暂时没有正文时，悬浮窗会显示「已运行 N 秒」的心跳，让你知道审查仍在进行。全部完成通常约 1~3 分钟（文献核对需读 PDF 原文，更久）。单次上限 6000 字符。

> 原理：悬浮窗（content script）**直接连接**本地桥接服务（Node）→ `claude -p --output-format stream-json` → 结果逐块回传悬浮窗。审查链路不经过扩展后台 service worker——MV3 的 SW 会被浏览器按生命周期回收，之前曾导致审查中途连接断开；弹窗直连后 SW 的生死不影响进行中的审查。
> 桥接服务工作目录默认是 `Documents\scientific_research`，可用环境变量 `CLAUDE_CWD` 修改；审查模型默认跟随 claude CLI 全局配置，可用环境变量 `REVIEW_MODEL` 指定（如 `REVIEW_MODEL=deepseek-v4`）。

### 安全说明

- 审查在**只读**模式下运行：Claude Code 只启用 Read / Glob / Grep 三个只读工具，并叠加 plan 只读模式与工具黑名单（写文件、执行命令、联网、启动子代理、定时任务等一律不可用）。
- 悬浮窗内容放在封闭的 shadow DOM 里，网页脚本读不到审查结果、也点不到里面的按钮；弹窗只响应真实鼠标/键盘操作（合成事件无效）。
- 选中文本会**原样**进入审查提示词：恶意网页可以用伪装指令诱导模型输出本地文件内容（只读范围内）。请勿在不信任的网页上点「论文审查」；桥接服务只绑定 `127.0.0.1`，且只在双击 `start-bridge.bat` 后才运行。
