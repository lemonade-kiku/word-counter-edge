# 选中字数统计（Edge 浏览器插件）

> GitHub 仓库：https://github.com/lemonade-kiku/word-counter-edge

用鼠标左键选中网页上的文字，会自动弹出一个悬浮小窗，显示选中内容的：

- **字数**（不含空格，汉字按字计）
- **词数**（汉字 + 英文单词）
- 字符数（含空格）、汉字数、英文单词数

## 安装方法

1. 打开 Edge 浏览器，地址栏输入 `edge://extensions/` 并回车
2. 打开左下角「开发人员模式」开关
3. 点击「加载解压缩的扩展」
4. 选择本文件夹（`word-counter-edge`）
5. 完成！随便打开一个网页，用鼠标左键选中一段文字试试

## 使用说明

- 鼠标左键拖选文本 → 悬浮窗出现在选区上方
- 双击选中单词、`Ctrl + A` 全选、`Shift + 方向键` 选择也支持
- 输入框 / 搜索框 / 评论框里的选中文本同样支持
- 悬浮窗**只有点击右上角 ✕ 才会关闭**；点击页面、滚动页面均不会收起，选中新文本时自动更新内容

## 常见问题

- **修改了代码不生效？** 回到 `edge://extensions/`，点插件卡片上的「重新加载」按钮
- **PDF 页面不显示？** Edge 自带的 PDF 阅读器不支持浏览器插件，属正常现象
- **不想要了？** 在 `edge://extensions/` 里直接关闭或删除该插件即可

## 📝 论文审查功能（v1.1.0 新增）

选中文本后，悬浮窗上多了一个 **「📝 论文审查」** 按钮。点击后，插件会把选中文本发送给**本地运行的 Claude Code**，按论文写作规范审查三方面：

1. **内容正确性**：语法、拼写、逻辑、事实表述
2. **表达地道性**：是否符合学术语体，有无口语化 / 中式英语
3. **写作规范**：句式结构、时态语态、标点、术语一致性、段内衔接

审查结果（总体评价 + 问题清单 + 修改建议 + 润色后版本）会直接显示在悬浮窗里，可一键复制。

### 使用前提（一次性准备）

1. 电脑上装有 **Node.js**（`node -v` 可验证）和 **Claude Code CLI**（`claude --version` 可验证）
2. **双击运行** `bridge\start-bridge.bat`，保持黑色窗口开启（服务地址 `http://127.0.0.1:8899`）
3. 回到 `edge://extensions/` 点「重新加载」，然后重新加载测试网页

之后每次使用：先双击 `start-bridge.bat`，再在网页里选中文字点「论文审查」即可。审查每次约需 30~90 秒，单次上限 6000 字符。

> 原理：插件 → 本地桥接服务（Node）→ `claude -p` 无头模式 → 结果回传悬浮窗。
> 桥接服务工作目录默认是 `Documents\scientific_research`，可用环境变量 `CLAUDE_CWD` 修改。
